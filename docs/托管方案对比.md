# 托管方案与实测对比

同一时刻（2026-11-22 晚，上海）在这条网络上测的。所有数字都是本机真实请求，不是估算。

## 1. 当前部署

| 角色 | 地址 | 状态 |
| --- | --- | --- |
| 中国大陆入口（静态，**推荐**） | https://mteacase.github.io/clouddisk/ | 可用，最快 |
| 中国大陆入口（静态，同源 API） | https://clouddisk-uv1.pages.dev | 可用，但慢且偶发断连 |
| API（JSON / 鉴权 / 配额） | https://clouddisk-uv1.pages.dev/api/* → Worker | 可用 |
| 大文件传输 | `r2.cloudflarestorage.com` 预签名直连 | 可用，快 |
| Worker（服务端上游） | https://clouddisk-api.xiatianyou53.workers.dev | 大陆 DNS 污染，仅服务端使用 |
| 腾讯云 EdgeOne（全球区） | https://clouddisk.edgeone.cool | **401 私有**，需控制台访问链接或绑定域名 |

> GitHub Pages 版本与 pages.dev 版本共用同一套 API：`web/config.js` 在 CI 里被改写成
> `apiBase: "https://clouddisk-uv1.pages.dev"`，Worker 的 CORS 允许跨源读取。

## 2. 实测数据

### 静态资源（首屏 + app.js）

| 主机 | 首页 | app.js（66 KB） |
| --- | --- | --- |
| `mteacase.github.io`（Fastly） | **0.88 s**（connect 0.26 s） | **1.36 s** |
| `clouddisk-uv1.pages.dev`（Cloudflare） | 8.85 s（connect 0.25 s） | 超时（>30 s） |
| `clouddisk.edgeone.cool`（腾讯全球区，国内节点） | 0.64 s（但 401） | 0.33 s（但 401） |

### 文件传输

| 通道 | 上传 | 下载 |
| --- | --- | --- |
| 浏览器 → Pages Function 代理 → Worker → R2 | ~60 KB/s（40 MiB / 11 分钟） | 40 MiB 被中断 |
| 浏览器 ⇄ R2 预签名直连 | 2.3 MB/s（Node）/ 0.8–1.4 MB/s（浏览器 12 MiB 用 8–15 s） | 2.6 MB/s（12 MiB 下载 2.7 s） |
| Node → R2 S3 接口 | 1.5 MB/s | 2.6 MB/s |

### 域名可达性

| 域名 | DNS | 结论 |
| --- | --- | --- |
| `*.workers.dev` | 污染到 `108.160.167.159` | 完全不可用 |
| `*.pages.dev` | 正常（104.18.x / 2606:4700x） | 可用但不稳定 |
| `*.github.io` | `185.199.11x.153`（Fastly） | 可用且快 |
| `github.com` | 20.247.166.64，连接超时 | 被墙（只能用 api.github.com 推送） |
| `r2.cloudflarestorage.com` | Cloudflare | 可用，快 |
| `*.edgeone.cool` | 119.36.225.67 / 36.249.95.107（国内） | 网络极快，但默认 401 私有 |

## 3. 结论

1. **静态资源放 github.io 是当前最优**：比 pages.dev 快一个数量级，且稳定。
   缺点是没有服务端函数，API 必须跨域打到 pages.dev。
2. **文件字节必须直连 R2**（已实现）：比经代理快 20–40 倍，这是可用与不可用的分界。
3. **API 的跨境延迟仍是瓶颈**（pages.dev 单次 1–9 秒）。要彻底解决只有三种办法：
   - 自有域名 + Cloudflare（DNS/SNI 干净，但仍出境）；
   - EdgeOne / 腾讯云**绑定域名**（可选中国大陆加速，需要 ICP 备案）；
   - 香港/新加坡 VPS 反向代理 Worker（月成本 ¥20–50，不备案也能用，延迟通常 30–80 ms）。

## 4. 切换方式

### 改 API 地址
- Cloudflare Pages 版本：`web/config.js` 保持 `apiBase: ""`（同源，走 Pages Function）。
- GitHub Pages 版本：改 `.github/workflows/pages.yml` 里生成 `_site/config.js` 的 `apiBase`。
- 本地预览：`apiBase` 留空即可（dev-server 同源）。

### 让 EdgeOne 变公开
1. 打开输出的 Console URL → 项目 → **域名管理**绑定一个域名（全球区不要求备案，
   若选中国大陆加速则必须备案）；
2. 或在控制台点 **Preview** 拿带签名的访问链接（`?eo_time=...`，短期有效）；
3. 公开后再把前端 `apiBase` 指向 API 地址即可。

### 加 VPS 中转（不备案、成本最低的“快 API”方案）
在境外/香港 VPS 上跑一个 30 行的反向代理（Caddy/Nginx）指向
`https://clouddisk-api.xiatianyou53.workers.dev`，然后把 `apiBase` 换成该 VPS 域名。
大文件仍然走 R2 直连，不消耗 VPS 带宽。
