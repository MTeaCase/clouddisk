# 凭据轮换清单（务必执行一次）

在对话里出现过三类凭据，都已经离开安全边界。按优先级处理：

## 1. R2 S3 密钥（最重要）

```
Access Key ID:     7f18b2c4…（32 位）
Secret Access Key: b89898fb…（64 位）
```

它现在作为 Worker secret `R2_ACCESS_KEY_ID` / `R2_SECRET_ACCESS_KEY` 使用——**签发预签名 URL 必需**，
所以不能直接删掉而不替换，按下面顺序做：

1. R2 控制台 → **Manage R2 API Tokens** → 新建一个权限为
   `Object Read & Write`、限定桶 `clouddisk` 的令牌；
2. 本地写入新值：
   ```powershell
   cd clouddisk\worker
   '{"R2_ACCESS_KEY_ID":"新的ID","R2_SECRET_ACCESS_KEY":"新的密钥"}' | Out-File s.json -Encoding ascii
   npx wrangler secret bulk s.json
   Remove-Item s.json
   ```
3. 验证：浏览器上传一个小文件（走直传通道）→ 200 且出现在列表里；
4. 回到控制台**删除旧令牌**。

同时把 `.secrets.local` 里的两行也更新掉。

## 2. GitHub Personal Access Token

`ghp_cWsx…nYkPKB` 是 classic PAT，拥有该账号全部仓库的读写权限。

1. https://github.com/settings/tokens → 找到该 token → **Delete**；
2. 如果以后还要用 CI，改用 fine-grained token，只勾 `MTeaCase/clouddisk` 的
   `Contents: Read and write` + `Pages: Read and write` + `Actions: Read and write`；
3. 注意：本机推送用的是 GitHub API（`github.com:443` 在这条网络被墙），
   新 token 同样通过环境变量 `GITHUB_TOKEN` 传给 `scripts/github-publish.mjs`，不要写进文件。

## 3. 腾讯云 EdgeOne API Token

`MBLQPTr+…=` 能在全球区部署项目。

1. 控制台 → API Token / 访问密钥管理 → 删除该 token；
2. 该项目（`makers-oweanck0gahc`）目前是**私有**状态，删除 token 不影响已部署内容，
   但之后无法再用 CLI 更新，除非重新签发；
3. 如果确定不用 EdgeOne（当前 401 私有、未绑域名），也可以直接把项目删掉。

## 4. 登录密码 / 会话密钥

```powershell
cd clouddisk\worker
'{"ACCESS_PASSWORD":"新密码至少8位"}' | Out-File s.json -Encoding ascii
npx wrangler secret bulk s.json
Remove-Item s.json
```

换 `SESSION_SECRET` 会让所有已签发的登录令牌立即失效（相当于强制下线）。

## 5. 没有泄漏、但也建议知道的

- `SESSION_SECRET` 只在 `.secrets.local` 与 Worker secret 里，未出现在对话中；
- 仓库是公开的，但**不包含**任何密钥：`.secrets.local`、`worker/.dev.vars` 都被 `.gitignore` 排除，
  发布脚本 `scripts/github-publish.mjs` 里也有显式排除名单；
- 公开仓库里能看到：账号 ID、R2 端点与桶名、项目 URL —— 这些不含凭证，无法直接访问数据。
