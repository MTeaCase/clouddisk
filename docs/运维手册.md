# 运维手册

面向“自己的云盘自己维护”的场景，所有命令都在 `clouddisk/` 目录下执行，并先设置：

```powershell
$env:CLOUDFLARE_API_TOKEN = "你的 API 令牌"
$env:CLOUDFLARE_ACCOUNT_ID = "766a7c0d3acf63918d9747bfcf5b4802"
```

## 改登录密码

```powershell
cd worker
'{"ACCESS_PASSWORD":"新密码至少 8 位"}' | Out-File secrets.json -Encoding ascii
npx wrangler secret bulk secrets.json
Remove-Item secrets.json
```

改完立即生效（新令牌签发用新密码；旧会话令牌在 30 天内仍有效，
要强制踢下线就同时更换 `SESSION_SECRET`）。

## 改配额（10 GiB / 9.5 GiB）

编辑 `worker/wrangler.toml`：

```toml
QUOTA_HARD_BYTES = "10737418240"   # 10 GiB
QUOTA_SOFT_BYTES = "10200690688"   # 9.5 GiB
```

然后 `cd worker && npx wrangler deploy`。数值含义：

- `SOFT`：达到即返回 `507`，停止上传（用户看到的“上限”）；
- `HARD`：分片完成时若总量越过它，会删除刚上传的对象并回滚。

改了 `HARD` 也要同步考虑 R2 免费额度（10 GB/月），否则可能开始计费。

## 看当前用量

```powershell
# 浏览器登录后在控制台执行，或用 curl：
curl -H "Authorization: Bearer <token>" https://clouddisk-uv1.pages.dev/api/usage
```

返回 `total / trash / live / objects / softLimit / hardLimit / remaining / uploadBlocked`。
数据是实时列举对象算出来的，不是估算值。

## 回收站

- 删除 → 进入 `_trash/<时间戳>/<原路径>`，可恢复；
- 每日 UTC 19:00（北京时间 03:00）Cron 清理 30 天前的条目；
- 想立即释放空间：界面侧栏「清空回收站」，或
  `POST /api/trash/purge {"all":true}`。

Cron 改了 `TRASH_RETENTION_DAYS` 后需要重新 deploy。

## 看日志

```powershell
cd worker
npx wrangler tail clouddisk-api --format pretty
```

只看错误：`npx wrangler tail clouddisk-api --status error`。

## 备份 / 迁移（用 R2 的 S3 接口）

R2 的 S3 凭证可以在控制台重新生成（不要用聊天里贴过的那套）。
装好 rclone 后：

```ini
# %APPDATA%\rclone\rclone.conf
[clouddisk]
type = s3
provider = Cloudflare
access_key_id = <新的 Access Key ID>
secret_access_key = <新的 Secret Access Key>
endpoint = https://766a7c0d3acf63918d9747bfcf5b4802.r2.cloudflarestorage.com
region = auto
```

```powershell
rclone ls clouddisk:clouddisk               # 看文件
rclone copy clouddisk:clouddisk D:\backup   # 全量拉回本地
rclone purge clouddisk:clouddisk            # 清空桶（危险）
```

注意：桶里 `_trash/` 是回收站、`*/` 结尾的零字节对象是文件夹占位符，都属于正常数据。

## 紧急停用

- 只想挡住别人：改密码（上方）；
- 想彻底停：`npx wrangler delete clouddisk-api`（删 Worker）或 Pages 项目里
  “暂停/删除部署”；R2 里的数据不会受影响；
- 恢复：重新 `npx wrangler deploy` + 重新部署 Pages。

## 常见故障

| 现象 | 排查 |
| --- | --- |
| 页面能开、登录 502 | 查 `API_ORIGIN` 环境变量是否指向正确的 Worker；`curl <worker>/api/health` |
| 上传卡在 0% 或反复失败 | 多为跨境链路问题，刷新后重试；确认单文件 < 5 GiB、单片 < 32 MiB |
| 提示“空间不足”但看着没满 | 回收站占用计入配额，清空回收站再看 |
| 中文文件名变下划线 | 旧版浏览器不支持 RFC 5987，换现代浏览器 |
| `wrangler dev` 起不来（Windows） | workerd 目录权限 bug，用 `node scripts/dev-server.mjs` |

## 费用

- R2：10 GB 存储 + 1M A 类 + 10M B 类请求每月免费，出网免费；
- Workers/Pages 免费版：10 万请求/天；
- 自限 10 GiB 且不开 Cloudflare Images 的情况下，通常每月 0 元。
